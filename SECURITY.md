# Sicherheitsrichtlinie

## Unterstützte Version

Aktuell wird nur der Stand im Branch `main` unterstützt.

## Sicherheitslücken melden

Bitte melde Sicherheitslücken **nicht** als öffentliches GitHub-Issue. Verwende stattdessen die private Funktion **Security → Report a vulnerability** im Repository oder kontaktiere den Repository-Eigentümer über sein GitHub-Profil.

Bitte füge möglichst folgende Informationen hinzu:

- betroffene Datei und Version bzw. Commit
- reproduzierbare Schritte
- erwartetes und tatsächliches Verhalten
- mögliche Auswirkungen
- falls vorhanden: ein vorsichtig getesteter Lösungsvorschlag

Veröffentliche keine Passwörter, privaten Schlüssel, Tokens, Zertifikate oder persönlichen Daten.

## Sicherheitsgrenzen

Dieses Projekt ist für Bastler, Entwicklung und private Testaufbauten in abgesicherten lokalen Netzwerken gedacht. Die Weboberfläche darf nicht direkt aus dem Internet erreichbar sein. Vor einem öffentlichen oder kommerziellen Einsatz sind zusätzliche Sicherheits-, Elektro- und Funktionstests sowie eine geeignete Produktionsumgebung erforderlich.
